## 📌 About the Project

The **Swiggy Sales Analysis Dashboard** is an interactive Microsoft Excel project that transforms food delivery data into meaningful business insights. It helps explore sales performance, order trends, customer ratings, and geographic sales distribution through clear and engaging visualizations.

The project demonstrates practical skills in data analysis, dashboard development, and business reporting.

## 🎯 Project Objectives

- Analyze sales and order performance across available dimensions.
- Identify sales trends across different time periods.
- Explore customer ratings and order patterns.
- Compare sales performance across cities and states.
- Present data in a clear, visual, and business-friendly format.

## 🛠️ Tools & Skills

- **Microsoft Excel**
- Data Cleaning and Analysis
- Pivot Tables and Charts
- Interactive Dashboard Design
- Data Visualization
- Business Intelligence and Reporting
